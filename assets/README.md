# Assets

Esta pasta centraliza os recursos visuais e sonoros do jogo.

## Situação neste projeto

O jogo **Real ou IA?** usa apenas texto e retângulos desenhados pelo próprio Pygame. Por isso não foi adicionado nenhum arquivo de imagem, som ou fonte externo.

O arquivo `imagens/spritesheet.bmp` veio do template da disciplina e não é usado pelo jogo. A fonte usada é a Arial do sistema (ou a fonte padrão do Pygame).

## Organização

- `imagens/`: sprites, fundos e ícones.
- `sons/`: efeitos sonoros e músicas.
- `fontes/`: fontes tipográficas customizadas.

## Boas práticas

- Use nomes de arquivo descritivos e sem espaços.
- Prefira formatos leves (`.png`, `.ogg`, `.wav`, `.ttf`).
- Registre a origem dos assets utilizados (quando externos), no `README.md` da raiz.
